# UiDo Course Model v0.1

The course model is the provider-neutral contract between source capture and every UiDo renderer.

## Provenance
- **source** — directly supplied dataset
- **derived** — generated by UiDo from source evidence
- **verified** — independently measured ground truth, used for validation unless explicitly promoted
- **conflict** — competing evidence retained
- **unknown** — insufficient evidence

## Geometry layers
Each hole can contain green F/M/B, multiple tees, fairways, rough, hazards, paths, woodland/context, routing and conflicts. Missing secondary features remain missing rather than being invented.

## Registration
Registration is separate from geometry and remains null until a measured OSM-to-imagery solution exists. Satellite imagery must never be stretched or rotated to conceal registration error.

A measured registration record should contain the exact transform parameters plus residual/error metrics.

## Refinement
Derived polygons retain source references, evidence, confidence, processing parameters, registration version and residual/error metrics. If satellite evidence disagrees with OSM, retain the OSM source and create a conflict record; do not silently replace it.

## Validation
Verified GPS/mapped geometry is consumed only after candidate extraction. Store predicted geometry, verified geometry, position error, directional error, validation source and timestamp.

## Current Overstone status
The model contains all 18 supplied green F/M/B anchors and the source-feature counts from the documented OSM capture. The original OSM GeoJSON and satellite raster are not currently in the repository, so the registration transform and refined polygons remain intentionally pending.
