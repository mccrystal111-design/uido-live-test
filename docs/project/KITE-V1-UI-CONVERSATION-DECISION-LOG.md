

### Player Profile editing Q&A — Club removal confirmation and bag count, confirmed 14 October 2026
- Removing a club from the bag requires a confirmation pop-up.
- Show the number of clubs in the bag (for example, “12 clubs”) so the golfer can see the count as the bag changes. No maximum-count denominator has been specified.
- Removing a club from the active bag does not erase its retained club/shot history.
- Documentation only; no Figma edits, app/code changes, or GitHub Actions.
