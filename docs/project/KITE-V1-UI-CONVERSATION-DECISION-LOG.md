

### Player Profile editing Q&A — Detailed club-row controls, confirmed 13 October 2026
- Each club has an editable row in the compact bag list. Tapping a row opens its detailed controls.
- The detailed editor includes the club type, carry distance, and total distance.
- Identify total distance as estimated unless the golfer has manually overridden it; show when a value is manually entered.
- The bag editor provides actions to add or remove clubs.
- Preserve inline Save/Cancel for the edited profile section. Documentation only; no Figma edits, app/code changes, or GitHub Actions.
