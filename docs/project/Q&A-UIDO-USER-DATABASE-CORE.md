### Q1 — One permanent customer identity
**Status:** Awaiting voice answer.

Should a UiDo customer have one permanent account/identity that follows them through everything — for example, create account → use Hawk → record rounds → upgrade to UiDo — with all existing data remaining attached to the same account?

Options:
- A. Yes — one permanent UiDo identity
- B. No — Hawk and UiDo should have separate accounts
- C. Something else

## Running design principles

- UiDo Core is the underlying customer/data platform.
- Hawk is a stripped-down product/experience built on UiDo Core.
- Upgrading from Hawk to UiDo should unlock additional capability without creating a new customer or migrating the customer's identity.
- Customer data should be designed so richer UiDo information can be added later without breaking the Hawk experience.
